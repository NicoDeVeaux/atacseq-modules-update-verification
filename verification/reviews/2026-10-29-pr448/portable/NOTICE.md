# Source and license provenance

The archived nf-core/atacseq sources, module snapshots and proposed patch retain
their MIT license and nf-core/atacseq team copyright in `LICENSE.pipeline` and
the source archives. No third-party tool binaries, container images or FASTQ
bytes are redistributed by this bundle.

verification repository; its source SHA and Git provenance are recorded in the
historical evidence manifest. The original strict campaign helper is retained
unchanged. A separate portable copy changes only the default reference path.
No independent license file was present in that verification repository at the
inspected source. The target reproducibility repository's owner should preserve
or establish its intended license for those authored scripts when packaging.

bundle; it does not change the archived pipeline's scientific source.
